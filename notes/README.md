Conhecimento versionado sobre o Claude Code / Agent SDK, acumulado ao longo do tempo — diferente da auto-memory do Claude (que é local, por máquina, e não entra no git).

Use este espaço para:
- Mudanças e novas features do Claude Code / Agent SDK, com data e versão quando souber.
- Decisões sobre o harness deste repo e por que foram tomadas.
- Padrões testados (o que funcionou, o que não funcionou) em memória, hooks, subagents, loop prompting.

Convenção: um arquivo por tema (ex: `agent-sdk.md`, `hooks.md`, `subagents.md`), não um arquivo por data. Cada arquivo cresce conforme o tema evolui.
